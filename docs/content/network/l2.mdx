## 用語解説

このページに出てくる L2 の用語です。

### VLAN

1 本の物理ネットワークを、論理的に分割する仕組みです。フレームに VLAN ID (IEEE 802.1Q のタグ) を付けて区別し、VLAN が違えばブロードキャストも届きません。このネットワークでは、DJ・AV・PA などの用途ごとに VLAN を分けています。

- **タグ付き (tagged)**: 複数の VLAN を 1 本のリンクで運ぶポートです。スイッチ間のトランクや、Kubernetes のノードがつながるポートに使います。
- **タグなし (untagged)**: 1 つの VLAN だけを通すポートです。端末を収容するポートに使います。
- VLAN 間の通信は L3 (FortiGate) を通り、そこで制御します ([FW](/network/fw))。

一覧は [VLAN 一覧](#vlan-一覧) を参照してください。

### VXLAN

L3 のネットワークの上に、L2 のネットワークを延ばすトンネル技術です。フレームを UDP に包んで運ぶので、間に L3 があっても、同じ L2 にいるように通信できます。このネットワークでは、Kubernetes の Pod を各 VLAN へ L2 で直接つなぐために、FortiGate の software switch と vxlan-cni で使っています。仕組みと設定は [VXLAN の実装](/computing/vxlan) を参照してください。

### スパニングツリー

L2 にループがあると、ブロードキャストが回り続けて、ネットワークが止まります (ブロードキャストストーム)。スパニングツリーは、冗長なリンクを論理的に塞いでループを防ぎ、使っているリンクが切れたときは塞いでいたリンクに自動で切り替えます。

- **RSTP**: 切り替えを速くした方式です。
- **MSTP**: VLAN ごとにツリーのインスタンスを分けられる方式です。
- **エッジポート / BPDU ガード**: 端末を収容するポートはツリーの計算から外します (エッジポート)。そこで BPDU を受けたら、誤ってスイッチをつながれたものとして、ポートを shutdown します (BPDU ガード)。

### リンクアグリゲーション

複数の物理リンクを 1 本の論理リンクに束ねて、帯域を増やし、リンクが 1 本切れても通信を続けます。

- **LACP**: 対向とネゴシエーションして束ねる方式です。設定の食い違いに気付けます。
- **静的**: ネゴシエーションをせず、手動で束ねる方式です。

### IGMP Snooping

マルチキャストは、受信したい端末だけに届けたい通信です。スイッチが何もしないと、マルチキャストは全ポートに流れます。IGMP Snooping は、端末が送る参加の通知 (IGMP) を見て、受信したい端末のつながるポートだけに転送します。**Querier** は、参加している端末を定期的に問い合わせる役で、VLAN ごとに 1 台が担います。

### PoE

LAN ケーブルで、通信と一緒に電力を送る仕組みです (Power over Ethernet)。AP などの機器に、電源ケーブルなしで給電できます。給電できる総電力とポートあたりの上限は、機種で決まっています。

## 共通設定

N-1 から先のスイッチは L2 として動き、全ての VLAN をトランクで運びます。

- **VLAN**: 全てのスイッチで同じ VLAN (10, 20, 30, 40, 42-45, 99, 100) を有効にしています。トランクは全ての VLAN を通し、ネイティブ VLAN は使いません。
- **スパニングツリー**: RSTP。N-3 (ApresiaLightGM110GT-PoE) は MSTP (インスタンス 0 のみ) で、RSTP と相互接続しています。端末を収容するポートはエッジポートにし、BPDU ガードで BPDU を受けたポートを shutdown します。
- **リンクアグリゲーション**:

  | スイッチ | インターフェース | ポート | 方式 | 用途 |
  | :--- | :--- | :--- | :--- | :--- |
  | N-1 | `po1` | `port2.0.5` - `2.0.12` | LACP | トランク |
  | N-1 | `po2` | `port2.0.13` - `2.0.20` | LACP | トランク |
  | N-1 | `sa1` | `port2.0.21` - `2.0.22` | 静的 | トランク |
  | N-4 | `po1` | `port1.0.17` - `1.0.24` | LACP | 上流へのトランク |
  | N-4 | `po2` | `port1.0.9` - `1.0.10` | LACP | AV (VLAN 20) の機器 |
  | N-4 | `po3` | `port1.0.11` - `1.0.12` | LACP | AV (VLAN 20) の機器 |
  | N-5, N-6 | `sa1` | `23` - `24` | 静的 | 上流へのトランク |

- **IGMP Snooping**: マルチキャストを使う DJ (VLAN 10) と AV (VLAN 20) では、N-1 が Querier になります (`10.10.0.2`, `10.10.16.2`)。
- **PoE**: 一部のスイッチは PoE で機器に給電できます。N-3 はポート 1 - 8 で給電します (装置全体 125 W、ポートあたり最大 31.2 W)。
