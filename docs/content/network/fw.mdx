## ファイアウォール (NGFW) とは

通信を、送信元・宛先・サービスなどのルールで、許可するものだけを通す仕組みです。許可していない通信は拒否します。NGFW (次世代ファイアウォール) は、これに加えて、アプリケーションやユーザーも見て制御できます。このネットワークでは、VLAN 間とインターネットへの通信を FortiGate が制御します。

## 役割

全ての VLAN のゲートウェイ、DHCP・DNS サーバ、VLAN 間とインターネットへの通信制御は FortiGate 100D (NGFW) が担います。ルーティングは [L3](/network/l3)、スイッチは [L2](/network/l2) を参照してください。

## DHCP・DNS

- 各 VLAN の DHCP の範囲は [VLAN 一覧](/network/l2#vlan-一覧) を参照してください。DHCP で配る DNS サーバは、多くの VLAN では FortiGate 自身です。
**VLAN 44 (CAM1) と VLAN 45 (CAM2) だけは、それぞれのカメラ用 CoreDNS の LoadBalancer IP (`10.12.77.253`、`10.12.77.254`) を配ります**。カメラが `api.ustream.tv` を中継用の Nginx に向けるためです ([ライブ配信](/service/live))。
- Kubernetes のノードは、FortiGate を DNS サーバにしています。
外部の名前は FortiGate が上流に転送し、`svc.technotut.net` は FortiGate が答えます。
- `svc.technotut.net` のゾーンと、逆引きの `12.10.in-addr.arpa`・`0.14.10.in-addr.arpa` は FortiGate が答えます。レコードは Kubernetes の ExternalDNS が REST API で書き換えます ([DNS (ExternalDNS と FortiGate)](/computing/deploy))。ゾーンに手でエントリを書くと消えます。
- NTP は公開 NTP サーバに同期し、NTP サーバとして時刻を配ります。
