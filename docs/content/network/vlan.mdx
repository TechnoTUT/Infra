## 各VLAN詳細設定
1. **`DJ` VLAN (VLAN 10)**: PRO DJ LINK対応のVLAN。CDJやXDJなどのDJ機器やrekordboxが動作しているPCを接続。\
ゲートウェイIPは `10.10.0.1`、DHCPは `10.10.10.1 ~ 10.10.15.254` の範囲で提供。マルチキャスト通信が必要であるため、IGMP Snoopingが有効であり、L3スイッチはIGMP Snooping Querierとして機能する。

2. **`AV` VLAN (VLAN 20)**: 映像伝送や配信に使用するVLAN。NDIプロトコルを使用する機器を接続。\
ゲートウェイIPは `10.10.16.1`、DHCPは `10.10.20.1 ~ 10.10.31.254` の範囲で提供。マルチキャスト通信が必要であるため、IGMP Snoopingが有効であり、L3スイッチはIGMP Snooping Querierとして機能する。

3. **`LBAR` VLAN (VLAN 30)**: 照明制御用のVLAN。Art-Netプロトコルを使用する機器を接続。\
ゲートウェイIPは `192.168.11.1`、機器には静的にIPアドレスを割り当てるため、DHCPは提供しない。

4. **`PA` VLAN (VLAN 40)**: PA機器用のVLAN。デジタルミキサーやiPadなどを接続。\
ゲートウェイIPは `192.168.12.1`、DHCPは `192.168.12.16 ~ 192.168.12.30` の範囲で提供。

5. **`ENT` VLAN (VLAN 42)**: エントランスや受付用の機器を接続するVLAN。\
ゲートウェイIPは `192.168.12.33`、DHCPは `192.168.12.34 ~ 192.168.12.46` の範囲で提供。

6. **`LDISP` VLAN (VLAN 43)**: LEDディスプレイ制御用のVLAN。\
ゲートウェイIPは `192.168.12.49`、DHCPは `192.168.12.50 ~ 192.168.12.62` の範囲で提供。

7. **`CAM1` VLAN (VLAN 44)**: カメラ配信用のVLAN。RTMPプロトコルを使用する機器を接続。\
ゲートウェイIPは `192.168.12.65`、DHCPは `192.168.12.66 ~ 192.168.12.78` の範囲で提供。

8. **`CAM2` VLAN (VLAN 45)**: カメラ配信用のVLAN。RTMPプロトコルを使用する機器を接続。\
ゲートウェイIPは `192.168.12.81`、DHCPは `192.168.12.82 ~ 192.168.12.94` の範囲で提供。

9. **`MGMT` VLAN (VLAN 99)**: ネットワーク機器管理用のVLAN。スイッチやルーターなどの管理インターフェースを接続。\
ゲートウェイIPは `192.168.99.1`、DHCPは `192.168.99.111 ~ 192.168.99.127` の範囲で提供。スイッチには静的にIPアドレスを割り当てる。

10. **`SV` VLAN (VLAN 100)**: サーバ用のVLAN。\
ゲートウェイIPは `192.168.99.129`、サーバには静的にIPアドレスを割り当てるため、DHCPは提供しない。

## 特殊用途VLAN (内部リンク用)
- **`wan`**: 対外接続回線 〜 IX3110 接続用: `192.168.8.0/24` (上流ルータ `.1`、IX3110 `.99`。IX3110 で NAPT)
- **`peer`(VLAN 101)**: 対外接続ルータ(IX3110 `.1`)とNGFW(FortiGate `.2`)間のダイナミックルーティング(BGP, AS 64646)用セグメント (`192.168.200.0/30`)
- **`nas`**: FortiGate の `port9` 〜 NAS 接続用: `192.168.98.0/30` (FortiGate `.1`、NAS `.2`)
- **`wan2`**: 予備の対外接続 (GL.iNet GL-AR300M) 〜 FortiGate 接続用: `192.168.9.0/24` (AR300M `.1`、FortiGate `.99`)
- **IPsec トンネル**: IX3110 と外部拠点の間の BGP 用セグメント
  - `Tunnel0.0` (ddlia-net): `192.168.250.0/30` (IX3110 `.2`、対向 `.1`)
  - `Tunnel1.0` (kisarag1-net): `192.168.250.8/30` (IX3110 `.10`、対向 `.9`)

## Kubernetes
- **Pod CIDR**: `10.11.0.0/16`
- **Service CIDR** (ClusterIP): `10.96.0.0/12` (kubeadm の既定値)
- **LoadBalancer IP**: `10.12.0.0/16` (BGPでFortiGateに広報)
  - `10.12.0.0`: bind9 (DNS)
  - `10.12.0.1` - `10.12.63.255`: 自動割り当て
  - `10.12.64.0` - `10.12.255.254`: 固定 IP (Service に `lbipam.technotut.net/static: "true"` ラベルが必要)
