## Beat Link Trigger とは
Beat Link Trigger は、AlphaTheta(Pioneer DJ)のDJ機器と連携し、曲情報を取得するためのツールです。\
コンピュータで仮想的なCDJを作成し、[PRO DJ LINK](/service/prodjlink)を用いて情報を取得します。

<RepoCard repo="Deep-Symmetry/beat-link-trigger" />

> [TechnoTUT Network](/)の[コンテナ基盤](/compute)で提供していた Beat Link Trigger の環境 (Debian GUI 環境の VM。`blt.svc.technotut.net`) は終了しました。\
> 曲情報・波形の表示、曲の履歴、Ableton Link の同期、OSC の送信 (Clojure の式) は、[plmux](/service/plmux) で提供しています。

## 機能
Beat Link Trigger は以下の機能を提供します。
- 曲情報・波形情報の取得・表示
- OSCによる対応外部機器との取得情報の共有
- httpによる取得情報の共有

## 使用方法
自分の PC で Beat Link Trigger を使う場合の手順です。
1. [Releases](https://github.com/Deep-Symmetry/beat-link-trigger/releases) から Beat Link Trigger をダウンロードして、PC にインストールします。
2. PC を DJ ネットワークにつなぎます ([PRO DJ LINK](/service/prodjlink) の「LINK Export 使用方法」と同じ)。
3. Beat Link Trigger を起動すると、自動で曲情報・波形情報が表示されます。\
   ![Beat Link Trigger](/img/service/beat-link-trigger_trackinfo.jpg)

Ableton Link は plmux が AV ネットワークに流しているので、Beat Link Trigger の Carabiner で Link に追従させないでください (テンポの元が 2 つになります)。

## 開発者向け情報
自分の PC の Beat Link Trigger で使う式の例です。plmux でも、ほぼ同じ書き方の式が使えます ([plmux の Clojure の式](/service/plmux#clojure-の式))。

### OSCによるBPM情報の送信

[Example: Send OSC message on each beat](https://github.com/Deep-Symmetry/beat-link-trigger/wiki/Example:-Send-OSC-message-on-each-beat)

Master PlayerのExpressionを設定します.

Setup Expression

```clojure
(swap! locals assoc :restap (osc/osc-client "<IP>" <PORT>))
```

Beat Expression

```clojure
(when trigger-active?
  (osc/osc-send (:restap @locals) "/osc/path" 1.0))
```

Shutdown Expression

```clojure
(osc/osc-close (:restap @locals))
```

### OSCによる曲名情報の送信

Master PlayerのExpressionを設定します.

Setup Expression

```clojure
(swap! locals assoc :oscblt (osc/osc-client "<IP>" <PORT>)) 
```

Tracked Update Expression

```clojure
(let [metadata track-metadata]
	(swap! locals update-in [:oscmetadata]
		(fn [old-metadata]
			(when (not= metadata old-metadata)
				(osc/osc-send (:oscblt @locals) "/osc/path" track-artist track-title))
			metadata)))
```

Shutdown Expression

```clojure
(osc/osc-close (:oscblt @locals))
```
