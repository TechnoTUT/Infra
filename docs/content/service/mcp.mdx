## MCP とは
MCP (Model Context Protocol) は、Claude Code や Claude Desktop などの AI アプリから、外部のデータやツールを使うための仕組みです。\
このドキュメントは MCP サーバーとしても公開されています。接続すると、AI アプリがこのドキュメントを検索して、必要なページを読めます。「VXLAN の設定はどうなっている？」のような質問に、手元のコピーではなく最新のドキュメントを根拠に答えられます。

## 接続方法
サーバーの URL は次のとおりです。認証は不要で、インターネットから接続できます。

```
https://network.technotut.net/mcp
```

### Claude Code
```bash
claude mcp add --transport http technotut-network-docs https://network.technotut.net/mcp
```

### その他のクライアント
Streamable HTTP に対応した MCP クライアントで、上の URL を指定します。

## 使えるツール
| ツール | 内容 | 引数 |
|---|---|---|
| `list_docs` | 全ページのパス、セクション、タイトルの一覧 | なし |
| `search_docs` | 全文検索。日本語と英語に対応。一致したページの抜粋を返す | `query` (必須)、`limit` (1〜20、省略時 5) |
| `read_doc` | ページ本文を Markdown で取得 | `path` (必須。例: `/network/fw`) |

AI アプリは、まず `search_docs` で探して、見つかったページを `read_doc` で読む、という順に使います。

### 質問の例
- FortiGate のファイアウォールポリシーはどう管理している？
- VXLAN で Pod を VLAN に接続する仕組みを教えて
- PA ネットワークの構成を要約して
