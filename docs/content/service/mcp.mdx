## MCP とは
MCP (Model Context Protocol) は、Claude Code や Claude Desktop などの AI アプリから、外部のデータやツールを使うための共通の仕組みです。\
このドキュメントは MCP サーバーとしても公開されています。接続すると、AI アプリがこのドキュメントを検索して、必要なページを読めます。「VXLAN の設定はどうなっている？」のような質問に、手元のコピーではなく最新のドキュメントを根拠に答えられます。

## 接続方法
サーバーの URL は次のとおりです。認証は不要で、インターネットから接続できます。

```
https://network.technotut.net/mcp
```

### Claude Code
```bash
claude mcp add --transport http technotut-network-docs https://network.technotut.net/mcp
```

### その他のクライアント
Streamable HTTP に対応した MCP クライアントなら、上の URL を指定するだけで使えます。\
Claude Desktop などの設定ファイルで URL を指定するときは、種類 (type) に `http` を選んでください。

## 使えるツール
| ツール | 内容 | 引数 |
|---|---|---|
| `list_docs` | 全ページのパス、セクション、タイトルの一覧 | なし |
| `search_docs` | 全文検索。日本語と英語に対応。一致したページの抜粋を返す | `query` (必須)、`limit` (1〜20、省略時 5) |
| `read_doc` | ページ本文を Markdown で取得 | `path` (必須。例: `/network/fw`) |

AI アプリは、まず `search_docs` で探して、見つかったページを `read_doc` で読む、という順に使います。

### 質問の例
- FortiGate のファイアウォールポリシーはどう管理している？
- VXLAN で Pod を VLAN に接続する仕組みを教えて
- PA ネットワークの構成を要約して

## 仕組み
- サイトと同じ Cloudflare Workers で動いています。`/mcp` だけが MCP サーバーで、そのほかのパスは、これまでどおりドキュメントのページです。
- ページの内容は、ドキュメントのビルド時に Worker へ取り込まれます。そのため、更新が反映されるのはデプロイが終わったあとです。
- 読み取り専用です。ドキュメントの変更や、ネットワークへの操作はできません。
- 状態を持ちません。セッションの開始や終了の処理はなく、ブラウザで URL を開いても `405` が返ります (MCP クライアント専用です)。

実装は [Infra リポジトリ](https://github.com/TechnoTUT/Infra) の `docs/worker/index.js` です。
