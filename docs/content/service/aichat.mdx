## AI チャットとは
AI チャットは、TechnoTUT の [コンテナ基盤](/compute)、ネットワーク、このドキュメントについて、日本語で質問できる Web チャットです。\
Kubernetes やネットワークに詳しくなくても、状態を確かめたり、つながらない原因を調べたり、使い方や構成を調べたりできます。必要なときは、画面の承認ボタンで一部の操作 (Pod の再起動など) も実行できます。

AI (Google の Gemini) が、質問に合わせてクラスタ、FortiGate、ネットワークの状態や [Infra リポジトリ](https://github.com/TechnoTUT/Infra) (このドキュメントとマニフェスト) を調べて答えます。

## 使用方法
1. [TechnoTUT Network](/network) の DJ ネットワーク (VLAN 10) か AV ネットワーク (VLAN 20) に接続します。
2. ブラウザで http://ai.svc.technotut.net へアクセスします。
3. 下の入力欄に質問を書いて、Enter で送信します (改行は Shift+Enter)。

AI が何を調べたかは、回答の上に灰色の文字で表示されます (例: `> list_resources kind=pod namespace=plmux`)。\
「新しい会話」を押すと、それまでのやりとりを忘れて最初からやり直せます。

### 質問の例
- クラスタの調子はどう？
- 動いていない Pod はある？原因も調べて
- plmux はどのノードで動いている？
- VLAN 44 (CAM1) の側から、ゲートウェイに届くか確かめて
- カメラが cam1 につながらない。FortiGate のポリシーで止まっていない？
- FortiGate は重くない？
- この MAC アドレスの機器は、どの IP を借りている？
- plmux を再起動して (承認ボタンを押すと実行されます)
- 新しいアプリを追加するにはどうすればいい？
- Argo CD って何？このクラスタでの使われ方を初心者向けに説明して

## できること・できないこと
| できる | できない |
|---|---|
| クラスタの状態を見る (Pod、Service、Ingress、ノード、Argo CD のアプリなど) | Secret (パスワードや API キー) を読む |
| Pod のログやイベントから、動かない原因を調べる | 承認ボタンなしで、クラスタを変更する |
| クラスタの Pod から、ping、DNS、TCP、HTTP で疎通を確かめる | FortiGate やスイッチの設定を変更する (読み取りだけ) |
| **VLAN の側から**、ping、arping、traceroute、DNS、TCP、HTTP を出して確かめる (VLAN 10、20、40、42〜45) | 設定の変更、削除、スケール、ノードの `drain` |
| FortiGate を読む (ポリシーとヒット数、DHCP のリース、経路、負荷、インターフェース) | VLAN 30 (LBAR) の側からの診断 (DHCP サーバがないため) |
| ドキュメントやマニフェストを読んで、使い方や構成を説明する | 変更の反映 (PR を作ってマージするのは人が行う) |
| 調べて問題が見つかったとき、運用担当の Discord に報告する | |
| 変更したいときの手順と、マニフェストの案を示す | |

### 承認ボタンで実行できる操作
AI が必要だと判断すると、画面に操作の内容と「実行する」「やめる」のボタンが出ます。**「実行する」を押したときだけ実行されます。** AI が勝手に実行することはありません。

| 操作 | 内容 | 対象 |
|---|---|---|
| Pod の再作成 | Pod を削除して、作り直させる | cam1、cam2、dmxctl、dmxsim、live、ndi、plmux、speedtest、time |
| rollout restart | Deployment・StatefulSet・DaemonSet を順に再起動する | 同上 |
| CronJob の手動実行 | CronJob から Job を 1 回作る | 同上 |
| Argo CD の Refresh / Sync | Git との差を再確認する、Git の内容に同期する | すべてのアプリ |
| ノードの cordon / uncordon | ノードに新しい Pod を置かせない、置けるように戻す (動いている Pod はそのまま) | becky、packard、marie |

- 提案は 10 分で期限切れになります。同じ提案は 1 回しか実行できません。
- 実行したか却下したかは、Discord に記録されます (操作、結果、送信元の IP)。
- 再起動すると、そのサービスは一時的に止まります。イベント中は特に注意してください。

### VLAN の側からの診断
「VLAN からつながらない」「FortiGate のポリシーで止まっていないか」のような疑いのときに、AI が使います。AI が必要と判断すると、検証用の Pod をその VLAN につないで起動します。初回は数十秒かかり、使い終わって数分で自動的に消えます。

## 自動の監視と通知
AI チャットとは別に、5 分ごとの自動チェックが動いています。**状態が変わったとき** (新しい問題が出たとき、重大度が上がったとき、復旧したとき) だけ、運用担当の Discord に知らせます。同じ状態が続いているあいだは通知しません。AI (Gemini) は使いません。

- クラスタ: ノード、Pod、ストレージ、LoadBalancer、Argo CD のアプリ、CronJob の失敗
- ノードの設定: DNS の設定のずれ、USB-DMX アダプタの認識、ディスクの空き
- ネットワーク: 外部の名前が引けるか、外に届くか、FortiGate の負荷
- FortiGate の設定変更: ポリシー、アドレス、DHCP などが変わったとき

見るもの、しきい値、仕組みは [監視と通知](/compute/monitoring) を参照してください。

## 注意
- AI の回答は間違えることがあります。イベント中の作業や、影響の大きい変更は、十分に注意して行うこと。
- 質問とクラスタの情報は、外部のサービスである Gemini API (有料枠) に送られます。**パスワードや個人情報は書かないでください。**
- Gemini API にはレート制限があり、使った分は課金されます。「上限に達しました」と出たら、時間をおいてから試してください。
- 画面にログインはありません。VLAN 10・20 につないだ人は、誰でも使えて、承認ボタンも押せます。
- リポジトリの内容は 5 分ごとに更新されます。マージした直後の変更は、まだ読めないことがあります。

仕組みと運用は [AI チャットの実装](/compute/aichat) を参照してください。
