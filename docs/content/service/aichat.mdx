## AI チャットとは
AI チャットは、TechnoTUT の [コンテナ基盤](/computing) とこのドキュメントについて、日本語で質問できる Web チャットです。\
Kubernetes やネットワークに詳しくなくても、クラスタの状態を確かめたり、使い方や構成を調べたりできます。

AI (Google の Gemini) が、質問に合わせてクラスタの状態や [Infra リポジトリ](https://github.com/TechnoTUT/Infra) (このドキュメントとマニフェスト) を読んで答えます。

## 使用方法
1. [TechnoTUT Network](/network) の DJ ネットワーク (VLAN 10) か AV ネットワーク (VLAN 20) に接続します。
2. ブラウザで http://ai.svc.technotut.net へアクセスします。
3. 下の入力欄に質問を書いて、Enter で送信します (改行は Shift+Enter)。

AI が何を調べたかは、回答の上に灰色の文字で表示されます (例: `> list_resources kind=pod namespace=plmux`)。\
「新しい会話」を押すと、それまでのやりとりを忘れて最初からやり直せます。

### 質問の例
- クラスタの調子はどう？
- 動いていない Pod はある？原因も調べて
- plmux はどのノードで動いている？
- 新しいアプリを追加するにはどうすればいい？
- VLAN の構成を教えて
- Argo CD って何？このクラスタでの使われ方を初心者向けに説明して

## できること・できないこと
| できる | できない |
|---|---|
| クラスタの状態を見る (Pod、Service、Ingress、ノード、Argo CD のアプリなど) | クラスタを変更する (再起動、削除、設定の変更) |
| Pod のログやイベントから、動かない原因を調べる | Secret (パスワードや API キー) を読む |
| ドキュメントやマニフェストを読んで、使い方や構成を説明する | スイッチや FortiGate を操作する |
| 変更したいときの手順と、マニフェストの案を示す | 変更を反映する (PR を作ってマージするのは人が行う) |

クラスタを変更したいときは、AI の案を参考に [Infra リポジトリ](https://github.com/TechnoTUT/Infra) に PR を作ってください。main にマージすると Argo CD が反映します。

## 注意
- AI の回答は間違えることがあります。イベント中の作業や、影響の大きい変更の前は、管理者に確認してください。
- 質問とクラスタの情報は Gemini API の無料枠に送られ、Google のサービス改善に使われることがあります。**パスワードや個人情報は書かないでください。**
- 無料枠には回数の上限があります。「上限に達しました」と出たら、時間をおいてから試してください。
- リポジトリの内容は 5 分ごとに更新されます。マージした直後の変更は、まだ読めないことがあります。

仕組みと運用は [AI チャットの実装](/computing/aichat) を参照してください。
